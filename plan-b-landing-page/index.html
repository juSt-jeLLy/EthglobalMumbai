05 / QUESTIONS

Know before you sign.

Does Plan B hold my funds?+

No. Plan B constructs the order and asks your wallet to sign it. Definitive Flash manages execution, while assets remain under your wallet’s control.

Which tokens are supported?+

Token support follows Flash’s live search catalog. When X renders a ticker card, Plan B resolves exact-symbol deployments and chooses the strongest-liquidity result per network.

Which wallets work?+

Injected EVM wallets such as MetaMask and Rabby are supported. Solana signing works with Phantom and compatible injected providers.

Does it read every tweet yet?+

Not yet. This release attaches to X ticker cards. Parsing arbitrary tweet text into structured trade signals is the next product layer.

Are these real mainnet orders?+

Yes. Review the asset, network, amount, execution strategy, quote, and wallet request carefully before signing.

What does the backend store?+

The backend protects service credentials and proxies API requests. Wallet private keys never leave the wallet and are never sent to the backend.
